box-sizing: content-box vs border-box

declared width: 300px

content-box

width: 300px

+ padding 20px x 2

+ border 10px x 2

Total: 360px

border-box

width: 300px

padding and border are inside it

Total: 300px

With content-box (the default), width only sets the content area, so padding and border are added on top and the box grows to 360px. With border-box, width covers content, padding and border, so the box stays at exactly 300px.
