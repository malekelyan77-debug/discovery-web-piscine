## About
This repository contains my work for the Git exercises of the Discovery Web Piscine. It shows how to create a local repository, make commits, connect to GitHub, and push changes, first over HTTPS and then securely over SSH.

## Why Git Makes Development Easier

Safeguarding code: If a bug or bad implementation breaks into the application, you can instantly revert back to a working state without losing previously saved work.

Tracking history: Every change is tracked with a commit history. you can inspect exact modifications made at any point in the project's lifespan.

Team collaboration: Developers can create independent branches to work on features, bug fixes, or experiments without disrupting the main codebase (main or master).

## Basic Git Workflow
```
git status                 # see what changed
git add hello.txt             # stage a file
git commit -m "message"    # save a snapshot with a message
git push                   # upload commits to GitHub
```
